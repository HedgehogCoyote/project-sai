## 검사

- 프로덕션 빌드와 Vue/TypeScript 타입 검사 통과
- Chromium 화면 검사 7개 통과 (모의 API 사용)
- 변경된 Vue 화면·E2E 파일 ESLint 오류·경고 없이 통과
- 브라우저에서 공간 진입, 상단 메뉴, 초대 완료, 생성 창, 로그아웃, 로그인↔회원가입 이동 확인

검사 7개: 로그인 폼, 로그인↔회원가입, 서버 계약의 공간 목록, 생성 후 새 공간 진입, 50자 공간 이름, 현재 공간의 초대 요청·성공, 공간 변경 시 초대 입력·오류 초기화 및 새로고침 위치 유지.

## 시안 대비 정리

목록의 중복된 새 공간 만들기 버튼은 왼쪽 하나로 통일했습니다. 공간·메뉴는 URL 쿼리에 유지합니다. 생성 창은 기본 dialog를 사용해 키보드 초점이 창 안에 머물도록 했습니다. 실제 초대 화면은 예시 안내 박스 대신 서버의 처리 중·완료·오류 결과를 표시합니다.

공통 컴포넌트 파일의 쓰기가 거부되어, 기존 인증·로고 마크업을 유지하고 공통 스타일에서 승인된 모습을 적용했습니다. 기존 인증 기능과 서버 요청은 유지했습니다.
