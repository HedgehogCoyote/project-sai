## 적용하려는 범위

- 왼쪽 메뉴는 모든 공간·참여 공간·공간 만들기로 제한합니다.
- 공간을 선택한 경우에만 본문 위쪽에 공간 홈 / 사용자 초대 메뉴를 표시합니다.
- 공간을 바꾸면 초대 입력값과 이전 결과를 초기화합니다. 초대 전송 중에는 공간 전환을 막아 다른 공간에 보낸 결과로 오해하지 않도록 합니다.
- 목록은 장식 그림 없는 표 형태로 바꾸고, 작은 화면에서는 항목을 줄바꿈합니다.
- 생성 창은 동일한 스타일로 변경하고 이름 1~50자, 처리 중 취소 방지, 오류 표시를 유지합니다. 생성 후 새 공간을 엽니다.
- 로그인·회원가입은 중앙 폼으로 정리합니다. 동작 없는 비밀번호 찾기는 제거하고 비밀번호 보기, 오류·진행 상태를 유지합니다.
- 계정 설정, 테마 전환, 기록·활동·여행·AI·공동 편집 메뉴는 현재 구현 대상에 넣지 않습니다.
- 서버 API와 데이터 모델은 변경하지 않습니다. 공간 정보는 기존 참여 공간 목록 응답을 사용합니다.

## 검증 계획

타입 검사와 프로덕션 빌드, 기존 화면 테스트의 변경된 문구·탐색 흐름 확인, 공간 선택/목록 복귀/생성/현재 공간 초대/오류/로그아웃을 검증합니다. 실제 화면 캡처와 모의 API 검증 여부를 별도로 보고합니다.

제품 반영은 이 자료의 명시적 승인 이후 진행합니다.
