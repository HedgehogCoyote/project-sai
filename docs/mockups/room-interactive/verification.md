# 목업 검증 기록

2026-10-06, 로컬 정적 서버와 인앱 브라우저에서 확인했습니다.

- JavaScript 문법 검사 통과: `node --check app.js`.
- 공간 목록에서 방 진입, 새 공간 생성 및 기본 가구 표시.
- 소파에 투표 기능 연결, 표시 이름 변경, 위치 변경, 배치 저장.
- 가구 클릭으로 투표 진입 및 선택 제출.
- 화분을 포인터로 직접 끌어 격자에 놓기: 위치 1,1 → 2,1 확인.
- 방 밖으로 이동 요청 차단, 저장 후 새로고침에서도 위치 유지 확인.
- 반복 할 일 회차 완료와 완료 기록 표시, 월별 규칙 생성·예정 목록 확인.
- 지출 40,000원 추가, 이벤트 완료 후 Foot Print 초안 생성.
- 후기 입력, 기록 게시, 액자 배치 후 방으로 복귀.
- 새 이벤트 생성과 선택한 기능 탭 표시.
- 최종 문법 검사 통과 후 테스트 데이터는 UI 초기화 기능으로 정리.

## 첨부 시안 반영 후 확인

- 투명 일러스트 가구 적용과 왼쪽 가구 목록·오른쪽 기능 설정 배치 확인.
- 이미지 교체 후 클릭 영역 보정: 소파를 눌러 연결된 반복 할 일로 진입 확인.
- 화분 드래그 이동 1,1 → 2,1, 취소 시 원래 배치 복귀 확인.
- 우측 인라인 반복 설정에서 업무 등록 후 목록·규칙에 반영 확인.
- Foot Print 사진 갤러리와 일러스트 액자 표시 확인.

모바일 레이아웃은 CSS 반응형으로 구현했으며 실제 모바일 장치 검증은 수행하지 않았습니다. 사진 업로드·저장 한도, 서버 연동, 다중 사용자 권한·동시 수정은 이 검증의 대상이 아닙니다. 세부 제한은 README를 참고하세요.

## 레이아웃 단순화·격자 보정 후 확인

이하가 현재 화면의 검증입니다. 위의 반복 할 일·Foot Print 검증은 이전 버전 기록입니다.

- 공간 목록, 방 메뉴, 도구 선택 모달, 가구 기능 연결 목록에서 반복 할 일과 Foot Print가 제외됨을 확인.
- 기존 연결 가구는 장식으로 전환되고 일반 할 일·공유 일정·투표·정산은 유지됨을 확인.
- 방 중심 화면과 오른쪽 이벤트/도구 목록, 편집 시 왼쪽 가구 목록·오른쪽 기능 연결 배치를 스크린샷으로 확인.
- 화분 직접 드래그: 위치 1,1 → 2,1. 편집 취소 후 원래 위치로 복귀 확인.
- 새 소파 추가 시 3 × 2칸 표시, 방 밖으로 이동 시 차단과 원래 위치 유지 확인. 테스트 추가 가구는 편집 취소로 정리.
- 격자 표시 토글과 배치 저장 후 화면 복귀 확인.
- 이벤트 상세 화면에서 Foot Print 안내가 제외됨을 확인. 이벤트 완료 확인창의 읽기 상태 안내를 확인하고 취소. 완료 제출은 이 검증에서 실행하지 않음.
- 가구의 중복 타원 그림자를 제거하고 바닥 접점을 기준으로 배치한 화면 확인. 화분 이미지 표시 영역의 다른 가구 조각도 제외.

## Cottage 분위기 적용 후 확인

- Steam 공개 갤러리의 실제 화면을 확인해 색상·조명·방 중심 구성 참고.
- 낮/저녁 전환 시 배경·벽·창문·조명이 함께 바뀌고 선택 버튼의 눌림 상태가 표시됨을 확인.
- 저녁 선택 후 새로고침해도 선택 유지 확인.
- 방 보기와 편집 화면을 스크린샷으로 확인. 책상 2 × 2칸과 기능 연결 메뉴 유지 확인.
- 분위기 레이어 적용 후 화분 드래그 1,1 → 2,1 및 편집 취소 확인. 책상 클릭으로 이벤트 정산 열기 확인.
- `node --check cottage.js` 통과.

## 실제 3D 전환 후 확인

- Three.js 로컬 모듈·GLB 모델이 로딩되고 WebGL 방이 표시됨을 브라우저 스크린샷으로 확인.
- 무광 재질, 따뜻한 하단 색조 셰이더, 낮/저녁 조명과 바닥 그림자 표시 확인.
- 가구 목록과 선택 패널이 실제 3D 모델 미리보기로 전환됨을 확인.
- 화분 이름표 드래그 1,1 → 2,1. 이후 방향 버튼으로 원래 위치 복귀.
- 소파 90도 회전: 점유 칸 3 × 2 → 2 × 3. 배치 저장·새로고침 후 회전 유지 확인. 세 번 더 회전하고 저장해 원래 방향으로 정리.
- 3D 책상 클릭으로 이벤트 지출 내역과 균등 분담 패널 진입 확인.
- 모바일 폭에서 가구 목록·방·연결 설정이 세로로 배치되는 화면 확인. 실제 모바일 기기 성능은 검증하지 않음.
- `node --check room3d.js` 통과. 운영 Vue 애플리케이션의 빌드 대상은 수정하지 않음.
