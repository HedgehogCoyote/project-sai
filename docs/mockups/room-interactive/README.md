# SAI 공유 방 인터랙티브 목업

독립적인 프론트 목업입니다. 기존 Vue 애플리케이션이나 서버 API를 변경하지 않습니다.

`index.html`을 HTTP 정적 서버로 열면 됩니다. 방은 Three.js WebGL로 표시하며 ES 모듈과 import map을 사용하므로 파일을 직접 더블 클릭해 여는 방식은 지원하지 않습니다. 외부 리소스는 SUIT 글꼴과 대표 사진 예시입니다. 3D 라이브러리와 모델은 로컬 파일입니다. API 요청, 실제 로그인, 초대 발송, 송금은 없습니다. 예시 데이터는 브라우저 localStorage의 `sai-room-mock`에 저장됩니다.

첨부 시안에 맞춰 `reference.css`와 `visual.js`에 시각 표현을 분리했습니다. `layout.css`와 `layout.js`는 공간 선택 → 방/이벤트 → 가구 편집의 단순한 구조를 제공합니다. 반복 할 일과 Foot Print는 메뉴·도구 선택·가구 기능 연결에서 제외했고, 이벤트 완료 시 기록 초안을 생성하지 않습니다. 이전 브라우저 저장 데이터는 보존하지만 제외된 기능의 가구 연결은 장식으로 전환합니다.

`cottage.css`와 `cottage.js`는 사용자가 참고한 [Virtual Cottage 2의 Steam 공개 화면](https://store.steampowered.com/app/2943180/Virtual_Cottage_2/)을 바탕으로 저녁빛 배경과 크림색 패널을 표현합니다. `room3d.js`가 방·가구·조명을 실제 3D로 교체합니다. 낮/저녁 선택은 별도의 `sai-cottage-time` 저장 키를 사용하며 가구 배치 데이터에는 영향을 주지 않습니다. 게임 이미지·가구 에셋은 복사하지 않았습니다. 배경 음향과 실제 시간에 따른 자동 전환은 없습니다.

## 현재 3D 구성

- Three.js 0.184.0, MIT 라이선스. 공식 npm 배포의 모듈·GLTFLoader·RoundedBoxGeometry를 `assets/vendor`에 보관합니다. GLTFLoader의 두 유틸리티 import 경로만 로컬 파일 구조에 맞게 변경했습니다.
- 가구: [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit), CC0. 실제 사용하는 GLB 10개와 라이선스는 `assets/models`에 있습니다. 소파·책상·선반·화분·러그, 책상 위 노트북·의자, 선반 위 책·작은 식물과 쿠션을 표시합니다. 고양이·액자·달력·방 구조는 기본 3D 도형으로 구성합니다.
- 셰이딩: 무광 MeshStandardMaterial에 높이에 따른 따뜻한 하단 색조를 `onBeforeCompile`로 추가합니다. 살구색 주광·크림색 환경광·보라색 보조광, PCFSoftShadowMap, ACES 톤 매핑을 사용합니다. 실사 재질이나 무거운 후처리는 사용하지 않습니다.
- 직교 카메라 시점 고정, 8 × 8 바닥 격자, 레이캐스팅 선택·드래그, 90도 회전과 겹침 검사. 방향 버튼·키보드 이름표 선택도 지원합니다. 회전 시 점유 칸의 가로·세로를 함께 바꾸고 저장합니다.
- 목록과 선택 패널의 미리보기는 동일한 3D 모델을 렌더링해 생성합니다. 초기 로딩 중에는 이전 2D 미리보기가 잠시 표시될 수 있습니다.
- 화면 변경 시 그림자 맵과 생성한 geometry/material을 정리하고 모델 캐시·단일 렌더러를 재사용합니다. 상시 애니메이션 루프 없이 변경 시에만 렌더링합니다.
- WebGL 사용 가능한 브라우저가 필요합니다. 실제 모바일 기기 성능, 다중 사용자 동시 편집은 검증하지 않았습니다.

## 이전 2D 가구 에셋

파일: `assets/furniture-atlas.png`. Codex 내장 이미지 생성 도구로 제작한 프로젝트용 에셋입니다. 사용자 첨부 이미지는 스타일 참고로 사용했습니다. 소파·책상·선반·화분·고양이·액자·러그·달력·완료 고양이의 투명 이미지를 화면에서 각각 표시합니다. 실제 결과 해상도는 1280 × 1280이며 표시 영역은 결과를 확인한 뒤 지정했습니다. 래스터 원본은 수정하지 않았습니다.

프롬프트 요약: 참고 시안의 따뜻한 아이소메트릭 일러스트 스타일로 원목·보라색 가구와 크림색 고양이를 제작. 투명 배경의 3 × 3 아틀라스에 9개 에셋을 분리하고 같은 시점과 재질 표현을 유지.

## 확인할 흐름

1. 공간 목록에서 공간에 들어갑니다. 새 공간을 만들고 초기 도구를 선택할 수 있습니다.
2. 방 꾸미기에서 가구 또는 이름표를 선택하고 격자에 끌어 배치합니다. 방향 버튼으로 이동하거나 90도 회전할 수도 있습니다.
3. 어떤 가구든 기능·표시 이름·연결 이벤트를 지정할 수 있습니다. 장식으로만 둘 수도 있습니다.
4. 배치 저장 후 가구를 누르면 연결 기능이 열립니다. 도구 바로가기도 제공합니다.
5. 공유 일정, 일반 할 일, 투표, 정산을 오른쪽 도구 목록에서도 열 수 있습니다.
6. 이벤트 생성, 기능 선택, 준비물 체크, 투표, 지출 추가와 균등 분담을 체험합니다. 이벤트 완료 후에는 준비 내용을 읽기 상태로 확인합니다.
7. 새로고침하면 저장한 데이터가 남습니다. 하단의 예시 초기화로 돌아갑니다.

## 목업의 범위

- 가구 위치는 8 × 8 격자, 바닥 기준입니다. 기본 방향의 소파·러그는 3 × 2, 책상은 2 × 2, 선반은 2 × 1, 나머지는 1 × 1칸입니다. 기존 배치가 새 크기와 충돌하면 빈 칸으로 조정합니다. 벽면 이동·실시간 협업은 제외합니다. 러그는 다른 가구와 겹칠 수 있습니다.
- 포인터에서 바닥 평면으로 레이를 쏴 격자 위치를 계산하고, 유효한 드롭 위치는 초록색·불가능한 위치는 붉은색으로 보여줍니다. 바닥 그림자는 3D 조명이 생성합니다. 점유 칸은 가구의 정확한 삼각형 충돌 형태가 아니라 단순화한 직사각형입니다.
- 새 이벤트는 공간 구성원 전체가 참여합니다. 투표 후보는 예시 고정값입니다.
- 할 일 데이터는 공간 단위이며 이벤트의 할 일 탭도 같은 공간 목록을 보여줍니다. 이벤트별 할 일 분리는 후속 구현 사항입니다.
- 공간 일정은 편집할 수 있고 이벤트 세부 일정·장소 검색은 읽기 예시입니다.
- 초대는 이름을 구성원에 추가하는 로컬 시뮬레이션입니다. 실제 접근 권한 검증·계정 인증은 서버 구현 사항입니다.
- 기능 숨김 시 가구의 연결 표시를 해제하며 기능 데이터는 보존합니다. 재추가 후 가구에 연결할 수 있습니다.
- 독립된 프로젝트 제안 검토용 화면으로, 운영 서비스가 아닙니다.
