초대함의 처리 상태

빈 목록·처리 중·오류·부분 성공을 구분해서 보여줍니다.

구현 전 시안동일한 화면에서 제공할 상태별 안내
01 · 빈 목록

아직 받은 초대가 없어요.

다른 멤버가 초대하면 여기에 표시돼요.

02 · 불러오는 중 / 조회 실패

받은 초대를 불러오고 있어요.

초대를 불러오지 못했어요.

조회에 실패한 상태를 빈 목록으로 표시하지 않아요.
03 · 수락 또는 거절 처리 중

여행 준비방

참여 요청을 처리하고 있어요.

다른 초대 처리·중복 클릭·화면 이동도 잠깐 막아요.
04 · 처리 실패 / 결과 확인

처리 결과를 확인하지 못했어요.

다시 불러와 현재 초대 상태를 확인해주세요.

통신이 끊겨도 실제로 처리됐을 수 있어요. 자동으로 다시 수락하거나 거절하지 않아요.
05 · 수락 성공 · 공간 목록 갱신 실패

공간 참여는 완료됐어요.

공간 목록을 불러오지 못했어요.

수락 요청을 다시 보내지 않아요. 목록 갱신 후 공간 이동을 제공해요.
06 · 이미 처리됨 / 다른 탭에서 변경

초대 상태가 변경됐어요.

최신 상태를 불러와 목록을 갱신해주세요.

이미 수락·거절된 초대는 처리 완료 목록에 표시하며 액션을 반복하지 않아요.
07 · 다른 초대로 이미 참여 중

여행 준비방

이미 참여 중인 공간이에요.

같은 공간의 다른 초대는 수락 버튼 대신 이동을 제공해요. 이 초대를 거절해도 기존 멤버 자격은 유지됩니다.
08 · 처리 완료 목록의 빈 상태

아직 처리한 초대가 없어요.

수락하거나 거절한 초대가 여기에 모여요.
