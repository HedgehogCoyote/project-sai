대학 동기 여섯 명의 부산 여행, 공간을 만든 날부터 방에 조개가 놓일 때까지

한 모임이 SAI를 처음부터 끝까지 쓰는 과정을 8단계로 그렸습니다. 왼쪽은 하는 일, 가운데는 그때의 방, 오른쪽은 그때 보는 화면입니다. 단계마다 지금 코드에 있는지 표시했습니다.

서버 구현됨 멤버 모두 같은 데이터 브라우저에만 저장 만든 사람만 보임 시안 단계 새로 만들어야 함
정리

지금 코드로는 3단계에서 흐름이 끊깁니다

공간과 초대는 서버에 있어서 1~2단계는 여섯 명이 함께 할 수 있습니다. 하지만 활동, 투표, 준비물, 정산은 만든 사람의 브라우저에만 저장됩니다. 지민이 투표를 열어도 나머지 다섯 명에게는 보이지 않습니다. 이 흐름을 실제로 쓰려면 아래 순서로 필요합니다.

  1. 활동·투표·준비물·정산 서버 저장 — 3~5단계를 여섯 명이 같이 보게 하는 기반입니다. 화면은 이미 있어서 저장 위치를 서버로 옮기는 작업이 중심입니다.
  2. 링크 초대 — 단톡방에 링크 하나를 올려 여섯 명을 모으는 단계입니다. 아이디 검색만으로는 모이기 어렵습니다.
  3. Foot Print와 사진 업로드 — 6단계. 파일 저장 위치, 용량 한도, 삭제 정책을 먼저 정해야 합니다.
  4. 기념품 배치와 공간 색 — 7~8단계. 방 배치는 이미 서버에 저장되므로 기념품 가구 종류와 Foot Print 연결만 더하면 됩니다.
