# SAI 임시 데이터 기반 세부 기능 구현 — 승인 범위

공간의 사람 목록은 실제 멤버 조회 API가 없어 **체험용 참여자 목록**으로 표시합니다. 실제 인원 수와 구분하며 역할 변경·내보내기를 구현하지 않습니다. 활동 참여자·담당자·정산에는 이 체험 목록을 사용합니다. 지출에 사용된 참여자는 활동에서 제거할 수 없도록 안내합니다.

기능 추가는 해당 위치에서 수행합니다. 기능 제거, 기록의 소속 이동, 영구 삭제는 이번 범위에 넣지 않습니다. 보관 활동은 읽기 중심으로 열고 보관 해제 후 수정합니다. 종료일은 시작일 이전일 수 없으며 날짜 미정 활동도 지원합니다.

## 임시 데이터와 서버 연결 방식

- 기존 인증·공간 생성/조회·사용자 초대 API 흐름은 유지합니다. 새 세부 기능만 로컬 데이터 저장소를 사용합니다.
- 화면 전체에 체험 데이터 안내를 표시합니다. 사용자 계정과 공간 ID별로 데이터 키를 나누고, Space와 Event의 소속을 별도로 저장합니다.
- 첫 진입에는 예시 데이터를 제공합니다. 이후 작성·수정 내용은 이 브라우저에 저장되며 새로고침으로 유지됩니다. 다른 브라우저·기기·사용자와 공유되지 않습니다.
- 타입과 데이터 접근 인터페이스를 분리하고, 화면은 그 인터페이스만 호출합니다. 나중에 서버 구현을 붙일 때 로컬 구현을 API 구현으로 교체합니다. 아직 없는 서버 엔드포인트를 구현된 것처럼 호출하지 않습니다.
- 저장 제한·실패가 발생하면 입력을 유지하고 재시도를 안내합니다. 로컬 저장은 실시간 협업이나 서버 권한 검증을 대신하지 않습니다.
- 지도는 저장 장소와 직접 입력 중심입니다. 외부 지도·장소 검색 제공자, 비용, API 키는 추후 별도 결정합니다. 외부 AI·송금 연결도 없습니다.
- 원화 균등 분담은 정수 계산으로 처리합니다. 나머지 금액을 고정 참여자 순서로 1원씩 배분하고, 전체 순잔액 합계가 0인지 검증합니다. 정산 제안은 이체 실행과 구분합니다.
- 일정은 한국 시간 기준이며 복수 여행 시간대는 추후 별도 설계합니다.

## 승인 후 검증 계획

| 시나리오 | 통과 기준 / 증거 |
| --- | --- |
| 기록·할 일·일정 작성과 수정 | 저장 후 목록·요약에 반영, 새로고침 후 유지 |
| 공간 A/B와 활동 간 이동 | 다른 공간 데이터·입력·오류가 섞이지 않음 |
| 기록 미저장 이동·저장 실패 | 이동 확인, 실패 후 입력 보존·재시도 |
| 활동 생성·날짜 오류·뒤로 이동 | 잘못된 기간 생성 방지, 단계 이동 시 입력 유지 |
| 활동 완료·보관·해제 | 기록 유지, 목록 필터와 읽기/수정 상태 일치 |
| 기능 추가 | 현재 위치에만 설치, 상단 메뉴 즉시 반영, 중복 방지 |
| 투표 제출·변경·마감 | 한 사람의 변경은 한 표 유지, 마감 뒤 변경 차단 |
| 정산·나머지·일부 분담 | 잔액 합계 0원, 제안 이체 합계와 잔액 일치 |
| 참여자 변경 | 지출 기록의 참여자를 임의로 제외하지 않음 |
| AI·협업·지도 예시 | 향후/체험 표시, 외부 서비스 요청 없음 |

타입 검사·프로덕션 빌드, 핵심 계산·저장·상태 전이 테스트, 브라우저 동작 검사와 실제 구현 화면 PNG를 제공합니다. 모의 API 검증과 실제 서버 검증은 구분해 보고합니다.
