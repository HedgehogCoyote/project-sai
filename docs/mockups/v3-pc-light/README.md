## 변경한 방향

계정 설정·테마 전환·프로필 편집·소셜 로그인·파일 첨부·송금·역할 변경 등 이번에 넣지 않을 요소를 제거했습니다. AI·공동 편집은 요청에 따라 향후 예시로만 남겼습니다. 공간과 활동의 탐색 범위, 명시적 기록 저장, 기능을 넣을 위치를 분명하게 했습니다.

## 검수

- PNG 32개 실제 포맷과 1440×1000 규격 확인
- 전체 화면을 캡처하고 4개 모아보기로 배치 검토
- 화면 너비 넘침 없음 확인

- 검색·필터·초대·정산 예시의 상태 일치 보정
