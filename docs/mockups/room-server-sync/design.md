# 맵 서버 연동 승인 자료

2026-10-11. 다음 작업 제안의 1번(맵 서버 연동)을 구체화한 설계다.
애플리케이션 소스는 아직 수정하지 않았다. PNG는 구현 전 시안이며 3D 영역은 기존 화면 캡처를 참고용으로 재사용했다.

## 화면과 동작

- editing.png: 기존 가구 편집 구조를 유지하며 공유 배치와 개인 설정을 구분한다.
- conflict.png: 409 시 초안 유지, 저장 차단, 최신 배치 확인과 내 초안 보기 제공.
- states.png: 조회 중/일반 멤버/저장 중/실패/기존 배치 가져오기/최신 배치로 새 편집.
- mobile.png: 390px에서 패널을 세로로 배치하고 가로 넘침을 검사한 시안.
- 일반 MEMBER에는 방 꾸미기와 가져오기 버튼을 숨긴다. 기능 사용 권한을 추가로 넓히지는 않는다.
- 충돌 후 최신 배치로 새 편집을 시작하려면 초안을 백업하고 취소 확인을 받는다. 최신 버전으로 충돌 초안을 자동 저장하지 않는다.
- 기존 로컬 배치는 명시적으로 가져와 편집 초안으로만 연다. 별도의 저장을 누를 때까지 서버에 업로드하지 않는다.
- 미저장 서버 방과 저장된 빈 방은 빈 배치로 표시한다. 기존 기본 가구의 자동 생성·업로드는 제거한다.

## API와 데이터 보존

- 기존 GET/PUT /api/spaces/{spaceId}/room을 사용한다. 서버 API와 스키마 변경은 포함하지 않는다.
- DTO 변환 시 w/h를 전송하지 않고 kind/rotation으로 복원한다. 서버 계약의 UUID·배치 검증을 맞춘다.
- GET은 공간과 요청 번호를 검사한다. unmount/공간 변경 시 취소하고 이전 응답을 무시한다.
- PUT은 마지막 성공 응답의 version으로 저장하며 성공 응답을 상태 기준으로 삼는다.
- 편집·입력·이동·중복 저장을 저장 중 잠근다. 401은 기존 인증 만료 흐름으로 전달한다. 403·네트워크 실패는 초안을 유지한다.
- event는 로컬 활동 ID이므로 공용 JSON에 전송하지 않는다. 활동 연결 가구의 module/label/event는 계정·공간·가구 ID별 로컬 연결 정보로 보존하고 공용 요소의 module/label은 비운다.
- 같은 계정·브라우저에서만 로컬 연결을 복원한다. 다른 계정에는 해당 가구가 장식으로 보인다. 공간 전체 기능 연결은 기존 module/label로 공유하되 콘텐츠 자체는 여전히 로컬임을 안내한다.
- 활동 연결을 보존하는 저장소 쓰기가 불가능하면 서버 PUT 전에 중단한다. 서버 저장 성공 뒤 로컬 연결 확정 실패에 대비해 원본과 복구 정보를 보존하고 부분 성공을 안내한다. 서버에는 성공한 것을 실패로 오인해 자동 재시도하지 않는다.
- 기존 sai:room:v1 배치는 삭제하지 않는다. 손상된 JSON은 가져오지 않는다. 저장 실패·충돌 시 편집 초안과 가져오기 원본을 유지한다.
- 낮/저녁 설정은 개인 로컬 설정을 유지한다. 실시간 알림·자동 병합·활동 서버화·검색 최적화는 이번 범위에 없다.

## 검증 계획과 통과 기준

| 시나리오 | 기준 | 증거 |
| --- | --- | --- |
| DTO 왕복·회전·활동 연결 | 서버 계약 일치, 8종 가구 크기 복원, 로컬 연결 보존, 미지정 필드 미전송 | 변환 단위 테스트 |
| 미저장·빈 배치 | 기본 가구 자동 저장 없음, 저장된 빈 배열 유지 | 요청 감시 E2E |
| 저장 후 재조회 | 같은 배치·최신 버전으로 재진입, 저장 중 중복 PUT 없음 | E2E·API 응답 |
| 권한 | MEMBER 편집/가져오기 숨김. OWNER/MANAGER 저장 가능. 서버 403에서도 초안 유지 | 권한별 E2E |
| 실패·충돌 | 네트워크 실패/409 시 초안 유지. 최신 확인만으로 PUT 없음. 최신 편집 전 취소 확인 | E2E |
| 로컬 가져오기 | 자동 업로드 없음. 명시적 저장 전 PUT 없음. 원본 삭제 없음 | 저장소·요청 감시 E2E |
| 활동 연결·복구 | 다른 계정에 로컬 event 미노출, 저장소 실패 때 연결 손실 방지, 부분 성공 명시 | 단위 테스트·E2E |
| 공간 전환·401 | 이전 공간 응답 미반영, 인증 만료 흐름, 저장 중 이탈로 성공 응답 유실 시 재조회 | E2E |
| 실제 서버 | 독립 계정 두 개로 권한·저장·다른 멤버 조회. 가능한 경우 실제 브라우저 흐름도 검증 | 실제 HTTP/API 또는 브라우저 결과를 구분해 기록 |
| 화면 | 데스크톱/390px 입력·버튼 가로 넘침 없음, 구현 시안 차이 기록 | 실제 구현 캡처 |

최종 검증은 타입 검사·빌드·관련 단위/E2E·백엔드 테스트다. 모의 API 검증을 실제 서버 검증으로 표현하지 않는다.
기능 완성의 기준은 권한·초안·로컬 연결을 보존하면서 공간 멤버가 동일한 서버 배치를 조회하는 것이다. 성능 수치 개선은 이 작업의 목표가 아니다.
