# SAI 브랜드 에셋

승인된 로고: **1안 · 이어지는 사이** (2026-10-06).

두 형태가 부드럽게 이어지는 심볼과 직접 그린 소문자 `sai` 워드마크를 사용합니다. 워드마크는 SVG 경로이므로 글꼴 설치에 영향을 받지 않습니다.

| 파일 | 용도 |
| --- | --- |
| `logo.svg` | 밝은 배경, README, 일반 헤더 |
| `logo-light.svg` | 어두운 배경, 로그인 브랜드 영역, 저녁 테마 |
| `logo-mark.svg` | 작은 심볼·축약 표시 |

색상은 보라 `#71576c`, 부드러운 보라 `#aa849c`, 크림 `#fff7eb`, 밝은 심볼 `#e4c7d8`입니다. 비율을 유지하며 사용하고, 작은 크기에서는 심볼만 표시합니다.

Vue 화면은 `frontend/src/assets/brand`의 동일한 에셋을 `AppLogo.vue`에서 사용합니다. 독립 목업에는 `docs/mockups/room-interactive/assets/brand`에 같은 파일을 포함합니다. 파일을 변경할 때 세 위치를 함께 맞춥니다. 브라우저 아이콘은 심볼을 크림색으로 바꿔 보라색 바탕에 표시합니다.

[선택한 로고와 비교 시안](../mockups/logo-directions/index.html)을 참고하세요. 과거 디자인 캡처는 당시 상태를 기록한 자료입니다.
