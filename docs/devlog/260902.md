# 2026-09-02 SAI 개발 기록

## 초대 기능 검증 및 예외 처리 보완

- `JoinSpaceRequest`, `DenySpaceRequest`의 `invitationId`에 `@NotNull` 검증을 추가했다.
- `MethodArgumentNotValidException`을 공통 예외 처리기에 등록해, 잘못된 요청을 `400 Bad Request`와 `VALIDATION_ERROR` 코드로 응답하도록 했다.
- `InvitationResponse`의 `invititationId` 오타를 `invitationId`로 수정했다.
- 사용자가 자기 자신을 초대할 경우 `SelfInvitationException`을 발생시키도록 초대 서비스에 검증을 추가했다.
- `SpaceService`에서 사용하지 않는 `SpaceInvitationRepository` 의존성과 import를 제거했다.

## 테스트 보완

- 순수 Mockito 단위 테스트인 `SpaceServiceTest`의 `@MockitoBean`을 `@Mock`으로 변경했다.
- `SpaceInvitationServiceTest`를 추가해 자신을 초대할 때 `SelfInvitationException`이 발생하는지 확인했다.
- `SpaceInvitationControllerTest`를 추가해 초대 수락 요청에서 `invitationId`가 누락되면 `400 Bad Request`와 `VALIDATION_ERROR`가 반환되는지 확인했다.

## 확인 사항

- 테스트 실행은 보류했다. 현재 환경에서는 Gradle Wrapper가 Gradle 9.5.1 배포본을 내려받는 과정에서 네트워크 권한 오류가 발생한다.
- 의존성 다운로드가 가능한 환경에서 다음 명령으로 전체 테스트를 확인한다.

```powershell
cd backend
.\gradlew.bat test
```
