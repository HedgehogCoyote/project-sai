# 2026-09-07 SAI 개발 기록

## 로그인 ID 사용자 검색 API

- `GET /api/users/search?loginId={검색어}` 엔드포인트를 추가했다.
- 검색은 로그인한 사용자만 사용할 수 있으며, 비로그인 요청은 `401 Unauthorized`로 처리한다.
- 검색어는 공백이 아니면서 2자 이상 20자 이하가 되도록 요청 DTO에서 검증한다.
- Spring Data JPA 쿼리 메서드로 로그인 ID 부분 일치·대소문자 무시·오름차순 정렬·최대 10명 조회를 구현했다.
- 응답에는 초대 대상 선택에 필요한 `userId`, `loginId`, `name`만 포함한다.
- 검색 결과가 없을 때는 오류 대신 빈 배열과 `200 OK`를 반환한다.

## 테스트

- 정상 검색 응답의 상태 코드와 사용자 필드를 검증했다.
- 비로그인 요청, 2자 미만 검색어, 검색어 누락을 검증했다.
- 검색 결과가 없을 때 빈 배열을 반환하는지 검증했다.
- 서비스에서 조회된 사용자 엔티티가 검색 응답 DTO로 변환되는지 검증했다.

## 확인 결과

- 사용자 검색 Service·Controller 테스트가 모두 통과했다.
- Gradle 빌드 결과는 `BUILD SUCCESSFUL`이다.
