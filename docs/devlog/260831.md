# 2026-08-31 SAI 개발 기록

## 직접 진행한 작업

- `SpaceServiceTest`를 작성해 공간 생성, 잘못된 사용자 ID 예외, 생성자의 `OWNER` 등록, 참여 중인 공간 목록 조회를 검증하도록 구성했다.
- `SpaceControllerTest`를 작성해 로그인 여부에 따른 공간 생성, 공간 이름 길이 검증, 참여 중인 공간 목록 조회 API를 검증하도록 구성했다.
- 공간 목록 응답의 `spaceId`, `title`, `role`, 구성원 수를 JSON 응답에서 확인하는 테스트를 추가했다.

## 확인한 결과

- Space 관련 테스트 9개를 실행했다.
- 3개는 통과했고 6개는 실패했다.
- Service 테스트는 테스트 대역 주입이 정상적으로 이뤄지지 않아 `NullPointerException`이 발생했다.
- Controller 테스트는 비로그인 공간 생성의 기대 상태 코드와 실제 상태 코드가 다르고, 공간 목록 응답의 구성원 수 필드 경로가 일치하지 않아 실패했다.

## 현재 상태

- Space Service와 Controller의 주요 동작을 다루는 테스트 시나리오 초안은 작성했다.
- 테스트 실패가 남아 있어 테스트 설정과 API 응답 계약을 다시 맞춰야 한다.
