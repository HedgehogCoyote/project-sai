# 2026-08-21 SAI 개발 기록

## 오늘 진행한 내용

### 1. Spring Boot 개발 환경 복구

오랜만에 프로젝트를 다시 실행하면서 STS가 백엔드 프로젝트를 인식하지 못하는 문제를 해결했다.

처음에는 STS 워크스페이스와 실제 프로젝트 경로를 모두 다음 폴더로 지정해 프로젝트를 자기 자신 안으로 다시 가져오고 있었다.

```text
C:\Project\project-sai\backend
```

워크스페이스를 프로젝트 외부 폴더로 변경하고 `backend`를 Existing Gradle Project로 다시 가져오도록 정리했다.

Gradle 동기화 과정에서는 STS가 Java 25로 Gradle 8.9를 실행하면서 다음 오류가 발생했다.

```text
Unsupported class file major version 69
```

프로젝트에 포함된 Gradle Wrapper 9.5.1과 JDK 21을 사용하도록 설정해 버전 충돌을 정리했다.

### 2. PostgreSQL 연결 및 데이터베이스 생성

`psql` 실행 시 PostgreSQL 사용자 대신 Windows 계정명인 `SSAFY`로 접속을 시도해 인증 오류가 발생했다.

다음과 같이 PostgreSQL 사용자와 기본 데이터베이스를 명시해 접속했다.

```powershell
psql -U postgres -h localhost -p 5432 -d postgres
```

Spring Boot 실행 시에는 SQL State `3D000` 오류가 발생했다. 접속 대상인 `sai` 데이터베이스가 아직 존재하지 않는 것이 원인이었다.

```sql
CREATE DATABASE sai;
```

데이터베이스 생성 명령을 확인했으며, 생성 후에는 Flyway가 초기 마이그레이션을 실행하게 된다.

`DB_PASSWORD`는 소스 코드에 직접 작성하지 않고 STS의 `Run Configurations > Environment`에 등록하는 방식으로 사용하기로 했다.

### 4. 세션 인증 API 보완

로그인 이후 프론트엔드에서 인증 상태를 확인할 수 있도록 현재 사용자 조회와 로그아웃 기능을 추가했다.

```text
GET /api/auth/me
POST /api/auth/logout
```

현재 사용자 조회 응답을 위한 `MeResponse`를 만들고, 세션에 저장된 사용자 ID로 사용자 정보를 조회하도록 `AuthService.getMe()`를 구현했다.

로그아웃에서는 다음 코드로 현재 세션을 만료시킨다.

```java
session.invalidate();
```

로그아웃 성공 시 응답 본문 없이 `204 No Content`를 반환하도록 구성했다.

### 5. Vue 연동을 위한 CORS 설정

Vue 개발 서버와 Spring Boot 서버의 출처가 다르므로 `/api/**` 요청에 대한 CORS 설정을 추가했다.

```text
Frontend: http://localhost:5173
Backend:  http://localhost:8080
```

허용 HTTP 메서드와 헤더를 지정하고 세션 쿠키를 주고받을 수 있도록 `allowCredentials(true)`를 적용했다.

프론트엔드에서는 API 요청 시 다음 옵션을 함께 사용해야 한다.

```typescript
credentials: 'include'
```

## 오늘 확인한 내용

- STS 워크스페이스와 가져올 프로젝트 폴더를 동일하게 지정하면 프로젝트 설명 충돌이 발생할 수 있다.
- 프로젝트가 제공하는 Gradle Wrapper를 사용하면 개발자마다 다른 Gradle 버전을 선택하는 문제를 줄일 수 있다.
- `psql`에서 사용자를 지정하지 않으면 운영체제 사용자명으로 접속을 시도할 수 있다.
- SQL 문장은 세미콜론으로 끝내야 하며 `postgres-#`는 입력이 아직 끝나지 않았다는 의미다.
- SQL State `3D000`은 접속하려는 데이터베이스가 존재하지 않을 때 발생한다.
- 세션 쿠키를 사용하는 교차 출처 요청에는 백엔드의 credentials 허용과 프론트엔드의 `credentials: 'include'`가 모두 필요하다.
