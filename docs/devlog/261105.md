# 2026-11-05 · 작업 공간 기초 기능 구현

기획서 v2의 P0 기능을 한 번에 구현했다. 사용자가 "모두 구현, 끊지 말고"라고 요청해, AGENTS.md의 시안 승인 대기를 이번 작업에 한해 건너뛰었다. 새 화면은 기존 cottage 테마와 앞서 만든 시안(공간 색, 사용 흐름, 2.5D 기념품)을 따랐다.

## 결정한 것

- 채팅은 A안: 댓글·공지 먼저, 실시간 채팅은 2차.
- 공유 콘텐츠는 항목별 테이블 대신 공간별 JSON 문서 + 버전. 충돌하면 최신 문서에 같은 변경을 다시 적용한다.
- 관계별 시작 기능: 연인(달력·기념일·위시리스트·기록), 친구(달력·투표·정산·기록), 동아리(달력·출석·회비·할 일).
- 기념품은 3D 받침대 + 2D 사진, 물건형은 코드로 만든 형태. 방 왼쪽 벽 선반에 최대 8개.

## 만든 것

백엔드 V5 마이그레이션과 `workspace` 패키지, 프론트 `components/workspace`, `FootPrintPanel`, `RelationTools`, 서버 저장소와 동기화, 초대 링크 화면, 알림함, 계정 설정. 자세한 구조는 [작업 공간 기능](../architecture/workspace.md).

## 검증

- 백엔드 67개, 프론트 단위 28개, 기존 E2E 59개 통과.
- 실제 서버에서 계정 두 개로 가입부터 기념품 열기, 추억 보관함까지 15단계 통과(`frontend/scripts/live-flow.cjs`).
- 동아리·연인 공간에서 회비·출석·기념일·위시리스트를 실제 서버로 확인.
- 390px 폭에서 가로 스크롤 없음 확인.

## 이어서 만든 것

- 추억 보관함(추억 탭)과 선반에 놓을 기념품 고르기.
- 사진 썸네일(EXIF 방향 반영).
- 공지·댓글 이모지 반응, 공간별 알림 끄기, 공간 안 찾기.
- 모바일 헤더와 새 공간 만들기 창 정리.

## 남은 것

- 비밀번호 찾기(이메일), 카카오 로그인, 푸시 알림: 외부 서비스 키가 필요하다.
- @멘션, 공지·댓글 검색, 축구 테마 팩.
- 이용약관·개인정보 처리방침(출시 전 필수), 신고·차단, 운영자 화면.
- 공유 콘텐츠의 항목 단위 권한, 사진 EXIF 위치 제거, 실시간 동기화.
- 활동을 만든 뒤 들어온 멤버는 그 활동의 참여자에 자동으로 들어가지 않는다. 참여자 선택에서 추가해야 한다.
