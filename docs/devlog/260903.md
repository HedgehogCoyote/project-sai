# 2026-09-03 SAI 개발 기록

## 저장소 공개 준비

- 저장소를 공개로 전환하기에 앞서 워킹트리와 Git 히스토리 전체를 자격 증명 패턴으로 검사했다. API 키, 토큰, 사설 키, 하드코딩된 비밀번호는 발견되지 않았고 DB 비밀번호는 첫 커밋부터 `DB_PASSWORD` 환경 변수로 처리되어 있었다.
- 테스트 픽스처와 devlog에 하드코딩되어 있던 실제 개인정보를 더미 값으로 교체했다. 전화번호, 개인 이메일, 로그인 ID, 평문 비밀번호가 대상이었다.
- `git filter-branch`로 커밋 22개 전체를 재작성해 위 값들을 히스토리에서도 제거하고, 커밋 author 이메일을 하나로 통일했다. 재작성 전 상태는 번들로 백업해 두었다.
- MIT `LICENSE`를 추가했다. 라이선스 없이 공개하면 저작권이 유보되어 제3자가 코드를 사용할 수 없다.
- 저장소 루트에 있던 알고리즘 풀이 문서를 제거했다.

## README 재작성

- 기존 README는 공간 기능이 미구현이고 프론트엔드가 Vue 기본 프로젝트 상태라고 설명하고 있어 현재 구현 상태와 맞지 않았다. 컨트롤러와 스토어를 직접 확인해 다시 작성했다.
- 프로젝트 개념과 핵심 흐름을 상단에 배치하고, 구현 상태 표와 API 표 3종, 데이터 모델 관계도를 추가했다.
- 프론트엔드 `AppLogo` 컴포넌트와 동일한 브랜드 마크를 `docs/assets/logo.svg`로 만들어 헤더에 넣었다.
- 로컬 환경에 종속된 절대 경로와 IDE 임포트 절차를 제거하고, 실행 명령을 bash 기준으로 정리했다.

## 초대 컨트롤러 테스트 작성

- `SpaceInvitationRequest`의 `spaceId`, `inviteeUserId`에 `@NotNull` 검증을 추가했다.
- 초대 서비스의 자기 초대 검증을 조회한 엔티티 대신 요청 DTO의 `inviteeUserId`와 비교하도록 바꿨다. 동작은 같지만 검증 대상이 요청 값이라는 의도가 분명해진다.
- `SpaceInvitationControllerTest`에 보낸 초대와 받은 초대 목록 조회 테스트, 비로그인 요청 테스트를 추가했다.

## 확인한 결과

- `SpaceInvitationControllerTest` 10개를 실행해 3개가 실패했다.
- `비로그인_수락_요청`과 `비로그인_거절_요청`은 `GET`으로 요청했으나 실제 엔드포인트가 `POST`라 `405`가 반환됐다. 거절 테스트는 `/deny`가 아닌 `/join`을 호출하고 있었다.
- `정상ID에서_받은_초대_목록_조회`는 `getSentInvitationList(2L)`을 스텁했으나 컨트롤러가 세션 사용자 `1L`로 `getReceivedInvitationList`를 호출해 스텁이 적용되지 않았고, 응답이 비어 `PathNotFoundException`이 발생했다.
- 통과한 7개 중 `정상ID에서_수락_요청`, `정상ID에서_거절_요청`, `잘못된_초대ID로_수락하면_404에러`는 본문이 비어 있어 검증 없이 통과하고 있다. 실패한 테스트보다 이쪽이 더 위험하다.

## 현재 상태

- 저장소는 공개 가능한 상태이며 개인정보 제거, 라이선스, README 정리를 마쳤다.
- 초대 컨트롤러 테스트는 작성 중이며, 실패 3건과 빈 테스트 3건이 남아 있어 아직 커밋하지 않았다.
